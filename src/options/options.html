qBittorrent Adder

Add a button beside magnet and .torrent links. Nothing is submitted until you click.

qBittorrent connection

The extension talks to qBittorrent's Web API from its privileged background context. Credentials are stored only in this Firefox profile and are never sent to webpages.

qBittorrent setup and network notes
  • Enable Tools → Options → Web UI → Web User Interface (Remote control) in qBittorrent.
  • Use the same host and port in the base URL. If you use a reverse proxy, use its public URL and path.
  • The extension logs in through /api/v2/auth/login when needed and re-validates the session before every submission. It also retries once after an expired session.
  • qBittorrent CSRF protection is supported: the extension rewrites the Origin/Referer headers only for its own background API requests to the configured host. Normal browsing requests are never changed.
  • This build uses Firefox's Manifest V2 install-time host access, which works with qBittorrent on private LAN addresses in Firefox 160. If you use the MV3 comparison build instead, Firefox may block the request; see the README for the network.lna.skip-domains workaround.
  • For a .torrent URL, qBittorrent downloads the file itself. The URL must be reachable from qBittorrent's network, not merely from this browser. Browser-only cookies, localhost URLs, or links requiring a VPN on this machine may fail.
  • If qBittorrent has a self-signed HTTPS certificate, Firefox must trust it before the extension can connect.

Permissions and privacy

  • storage — saves settings, credentials, and optional history locally.
  • webRequest / webRequestBlocking — makes only the extension's own qBittorrent API requests look same-origin so qBittorrent CSRF protection accepts them.
  • Host access — the Manifest V2 <all_urls> permission is granted at install time for page scanning and direct background requests to your qBittorrent host. No page data is transmitted anywhere.
  • No telemetry, analytics, cloud sync, or third-party requests. Credentials use local storage, not Firefox Sync.
